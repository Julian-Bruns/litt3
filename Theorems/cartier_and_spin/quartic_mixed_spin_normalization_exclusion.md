# A quartic spin normalization cannot have a mixed simple branch fiber

Version1,2 October2026. Substantial computation-free proof passed [independent whole-implication review](../../Research/audits/QUARTIC_MIXED_SPIN_NORMALIZATION_AUDIT_2026_10_02.md).

Retain BOTH actual finite étale maps from the SAME smooth source to fixed X and a genus-two Y, and its actual Galois spin refinement q:T→Y. Let L=φ*M, L¹⁶=ωT, and φ:T→Γ be its separating normalized projective spin-image map. Suppose degφ=4, the canonical different is EXACTLY q*P for one point P∈Y, and every target point under that q-fiber has profile(2,1,1). Then this actual spin normalization is impossible.

No condition that P be Weierstrass is imposed. The canonical different section has zero first and third module traces. Its even quartic characteristic polynomial produces an ACTUAL involution over Γ with fixed points; theta recognition contradicts étaleness of the original X maps.

Combined with the separately established uniform-fiber obstruction, this excludes the entire quartic one-fiber spin-normalization branch. The higher-degree extraction and original unmarked common-cover problem remain open.
