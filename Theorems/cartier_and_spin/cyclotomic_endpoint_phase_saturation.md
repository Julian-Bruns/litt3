# An endpoint character uses every phase or is absent

Version1, 27 September2026. In characteristic five, a nonempty subset
S of mu29 has sum zero if and only if S=mu29. This assertion concerns
distinct phases, not arbitrary multisets.

Consequently let D be a nonconstant squarefree monic polynomial whose
roots lie in a scalar multiple a0 mu29, with a0!=0. Then
\[
zD''+2D'=0\quad\Longleftrightarrow\quad D=z^{29}-a_0^{29}.
\]
Applied under the hypotheses of the local endpoint-character lemma
in [pole18 descent](pole_eighteen_cubic_descent.md), the residual
character therefore requires ALL29 distinct phases. In particular
it is excluded whenever that lemma applies with fewer than29 phases.

This is a conditional extension of the local lemma. It does not by
itself balance arbitrary higher multiplicities, eliminate their other
characters, prove descent at every pole below87, or construct a shared
object for an arbitrary common cover.
