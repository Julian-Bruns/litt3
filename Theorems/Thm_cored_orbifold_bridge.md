# A cored bi-etale span has a common effective orbifold

Over an algebraically closed field of arbitrary characteristic, let
X <-f- Z -g-> Y be finite etale maps of smooth projective connected
curves with g(X),g(Y)>=2. Suppose the intersection of the two endpoint
function fields inside k(Z) has transcendence degree one.

There is a connected finite etale refinement W -> Z whose composites
to BOTH endpoints are Galois. There is a smooth proper connected
effective DM curve S with representable finite etale atlases X -> S
and Y -> S, whose coarse function field is exactly that intersection.
Wild stabilizers and non-Galois original legs are allowed.

The core hypothesis is essential to this construction; this is not
a simultaneous-Galois-closure assertion for arbitrary spans.

Evidence: author proof, `/root/x_elliptic_quotient_maps`, 2026-09-05,
using the cited core theorem. [Proof](../Solutions/Sol_cored_orbifold_bridge.md).
