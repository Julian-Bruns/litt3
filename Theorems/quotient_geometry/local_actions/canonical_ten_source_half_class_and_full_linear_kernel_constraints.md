   \(1\to\mu_2\to H_L\to H\to1\).
3. If the ACTUAL matrix image \(H_0\) is centrally closed, then
   \(N_0=\ker(H\to H_0)\) has even order and is noncentral in \(H\).
   In particular faithful, odd-kernel and central-kernel realizations are
   excluded. Central closure of an ambient linear group does not suffice
   for a proper matrix subgroup.
