# A wild ramified spin quotient has exactly one wild and one tame branch value

Version2,3 October2026. The computation-free global reduction passed [independent whole-implication review](../../Research/audits/WILD_RAMIFIED_SPIN_TWO_BRANCH_AUDIT_2026_10_02.md); its exact ledger and pure-inertia extension passed [focused independent review](../../Research/audits/WILD_PURE_INERTIA_PROFILE_EXTENSION_AUDIT_2026_10_03.md).

Retain both ACTUAL finite étale maps from the same source, the actual minimal Galois spin source q:T→Y, and separating higher-genus image φ:T→Γ whose different is exactly one reduced q-fiber qP of local index two. Put k=|ker(G→AutΓ)|∈{1,3}, n=degφ/k and B=Γ/(G/K).

If Γ→B has ANY wild inertia, then B=P¹ and this actual Galois quotient has EXACTLY TWO geometric branch values: one wild and one tame. Every inertia order divides n. Three or more branch values and two wild branch values are impossible by the exact Hurwitz area1/n. A lone wild branch value would produce a nonzero regular exact differential on the ordinary Y and is likewise impossible.

This leaves a precise two-branch wild quotient case, together with the separate tame classification. It does not construct an étale X atlas or solve the unmarked common-cover problem.

inertia order and different, and m the tame inertia order, then
\[
(n/e)(\Delta-e)=n/m+1,
\qquad\operatorname{lcm}(e,m)=n.
\]
