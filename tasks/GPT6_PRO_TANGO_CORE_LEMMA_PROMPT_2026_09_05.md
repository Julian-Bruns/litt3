# Tango-core Pro request — DISPROVED

Date: 2026-09-05. This request was sent externally and answered.
Do not reuse it as an open target.

The failed lemma asserted that a projective finite etale span
X <- Z -> Y must have a nonconstant function-field core if separating
rational functions t_X,t_Y satisfy

    div(dt_X) in 5 Div(X),   div(dt_Y) in 5 Div(Y),
    f*t_X = u^5 g*t_Y + v^5.

Pro supplied a compact quaternionic Igusa counterexample with endpoint
genus 41, source genus 481, and both legs etale of degree 12.

The [counterexample, audit verdicts, and structural lessons](../routes/global/IGUSA_TANGO_COUNTEREXAMPLE_AND_RETAINED_SECTION_BOUNDARY.md)
replace the obsolete request instructions. The original reduction
retained an actual shared Cartier-zero pluriform, which this broader
lemma forgot. A subsequent [additive counterexample](../routes/global/CORELESS_PROJECTIVE_ETALE_SINGLETON_TANGO_COUNTEREXAMPLE.md)
also disproves the stronger universal claim retaining that form and
uniqueness. Neither result settles Litt's conjecture.
