# Statement

Let `P ⊂ Aut_k k[[z]]` be a finite `5`-group. For `σ∈P`, define

`j(σ)=v_z(σ(z)-z)-1`.

Let the lower ramification filtration be

`P_i = { σ∈P : j(σ) ≥ i }` for `i≥1`.

Define the wild excess

`ε(P)=Σ_{i≥1}(|P_i|-1)`.

Then

`ε(P)=Σ_{σ∈P, σ≠1} j(σ)`.

Hence

`ε(P)-(|P|-1)=Σ_{σ∈P, σ≠1}(j(σ)-1)`.

# Context / motivation

This identity rewrites the local ramification contribution in a form suitable for group-character and Swan-conductor divisibility arguments. It is one of the basic inputs for the local theorem replacing the false formal Artin–Schreier stabilizer bound.

# Proof or evidence

For each nontrivial `σ`, the element `σ` contributes `1` to `|P_i|-1` exactly for the integers `i` with `1≤i≤j(σ)`. Therefore summing over filtration levels and interchanging the order of summation gives

`Σ_{i≥1}(|P_i|-1)=Σ_{σ≠1} #{i≥1 : i≤j(σ)}=Σ_{σ≠1}j(σ)`.

Subtracting `|P|-1 = Σ_{σ≠1}1` gives the second identity.

# Dependencies

None.

# Failure points / caveats

- Check indexing conventions: some texts define lower groups using `v(σ(z)-z)≥i+1`; this file uses the project convention through `j(σ)`.
- The identity is formal; it does not by itself imply the local divisibility theorem.

# How this is used

Used directly in `THM-LOCAL-SWAN-DIVISIBILITY`, where the divisibility of `ε(P)-(|P|-1)` is translated into a statement about the sum of shifted breaks over nontrivial group elements.

# Related items

`THM-LOCAL-SWAN-DIVISIBILITY`; `REF-LOCAL-SWAN-PROOF`; `PROP-NONWEAK-WILD-EXCLUSION`.

# Statement

For finite 5-subgroup P⊂Aut_k k[[z]] with first lower break 1 and q=dim_F5 P/P2, 5^{ceil(q/2)} divides epsilon(P)-(|P|-1).

# Context / motivation

This is the actual local theorem replacing false formal Artin–Schreier and overstrong congruence arguments.

# Proof or evidence

Proof uses Swan conductor integrality, the regular representation, decomposition into irreducibles, and twisting by Hom(P/P2,C×); characters factoring through P/P2 contribute zero and nontrivial-on-P2 orbits contribute the required power of 5.

# Dependencies

LEM-WILD-EXCESS-IDENTITY

# Failure points / caveats

Needs formal proof audit. Do not strengthen it to individual break congruences without proof.

# How this is used

Constrains tails in non-weak wild over-orbifold arithmetic.

LEM-WILD-EXCESS-IDENTITY; PROP-NONWEAK-WILD-EXCLUSION; FALSE-FORMAL-STABILIZER-BOUND

status: locked

# Statement

Let

`I = P ⋊ C_T ⊂ Aut_k k[[z]]`,

where `P` is a finite `5`-group and `T` is prime to `5`. Let `χ` be the fundamental tame character.

For a lower break `b`, the graded piece

`P_b/P_{b+}`

is an `F_5[C_T]`-module on which `C_T` acts by the `b`-th power of the fundamental tame character, up to the project’s sign convention.

In particular,

`ord_{T/gcd(T,b)}(5)` divides `dim_F5(P_b/P_{b+})`.

# Context / motivation

This is the key representation-theoretic constraint used in the local-search algorithm and in the over-orbifold wild exclusions. It restricts which break positions and dimension drops can occur under a tame quotient.

# Proof or evidence

The tame generator acts on the parameter by multiplication through the fundamental tame character. Conjugating an infinitesimal wild automorphism at lower break `b` scales its leading term by the `b`-th power of that character. Therefore the `C_T`-character on the graded piece is in the Frobenius orbit of `χ^b`.

Over `F_5`, the dimension of the irreducible module generated by `χ^b` is the Frobenius orbit length of `χ^b`, namely

`ord_{T/gcd(T,b)}(5)`.

Thus that number divides the total `F_5`-dimension of the graded piece.

# Dependencies

None.

# Failure points / caveats

- The sign convention for `χ^b` versus `χ^{-b}` should be checked, but the orbit length/divisibility consequence is unaffected by inversion.
- This is a necessary local constraint, not a sufficient condition for a formal break sequence to be realized by an actual finite subgroup of `Aut k[[z]]`.

# How this is used

Used in:

- `LEM-ATMOST-ONE-WILD`;
- `ALG-LOCAL-SEARCH`;
- non-weak wild arithmetic filtering;
- tame-character condition at every break.

# Related items

`LEM-ATMOST-ONE-WILD`; `LEM-SUMMATION-BY-PARTS-TAME`; `ALG-LOCAL-SEARCH`; `COMP-LOCAL-ARITHMETIC-CHECKS`.

# Statement

Local Lie obstruction:

If lower graded pieces occur at breaks `r` and `s` with

`p ∤ (s-r)`,

then commutators force a nonzero piece at break `r+s`, subject to the usual nonvanishing hypotheses for the leading terms.

In maximal-break arguments this implies that nonzero breaks must often share a common residue modulo `p`.

For this project, `p=5`, so the obstruction is used as a common-residue constraint modulo `5`.

# Context / motivation

This lemma is one of the local necessary conditions used to reject formal lower-break sequences. It prevents the search algorithm from treating arbitrary congruence patterns as potentially realizable local ramification filtrations.

# Proof or evidence

The underlying calculation is the standard leading-term commutator computation in `Aut_k k[[z]]`: the bracket of two vector-field-like leading terms at breaks `r` and `s` has leading break `r+s` unless the coefficient vanishes. The coefficient includes a factor sensitive to `s-r`; if `p∤(s-r)`, the leading commutator is forced to be nonzero.

Thus, if a proposed filtration has breaks `r` and `s` but no compatible later break at `r+s`, it cannot come from an actual finite local group.

# Dependencies

None.

# Failure points / caveats

- The item should be used as a necessary obstruction, not as a complete classification of possible local groups.
- Nonvanishing hypotheses and indexing conventions must be checked in any formal proof.
- The archive warns that local formal survivors must still be rejected if they are not actual finite subgroups.

# How this is used

Used in `ALG-LOCAL-SEARCH` and in the non-weak wild exclusion to enforce common-residue conditions on break data.

# Related items

`ALG-LOCAL-SEARCH`; `PROP-NONWEAK-WILD-EXCLUSION`; `COMP-LOCAL-ARITHMETIC-CHECKS`; `DISCARD-SCHMID-WITT-CONGRUENCE`.

# Statement

Let the lower breaks and dimension drops be

`b_1 < b_2 < ... < b_r`, with drops `q_i`.

Assume the tame-character divisibility condition

`T | b_i(5^{q_i}-1)`

for every break layer.

Then the project’s summation-by-parts expression for the wild excess,

`ε = Σ_i b_i 5^{d_i}(5^{q_i}-1)`,

satisfies

`T | ε`.

# Context / motivation

This lemma converts local tame-character constraints into a global divisibility constraint on the wild excess. It is used in the arithmetic filtering for non-weak wild over-orbifolds.

# Proof or evidence

Each term in the summation-by-parts expression contains the factor

`b_i(5^{q_i}-1)`.

By the tame-character condition this factor is divisible by `T`. Multiplication by `5^{d_i}` does not affect divisibility by `T` because `T` is prime to `5`. Therefore every summand is divisible by `T`, and hence `T | ε`.

# Dependencies

- `LEM-TAME-CHARACTER-GRADED`.

# Failure points / caveats

- Check the indexing and definition of `d_i` when importing this into scripts.
- The divisibility is necessary, not sufficient, for local realizability.
- It assumes the tame-character condition at every break; omitting even one layer invalidates the conclusion.

# How this is used

Used in:

- `PROP-NONWEAK-WILD-EXCLUSION`;
- `COMP-LOCAL-ARITHMETIC-CHECKS`;
- `ALG-LOCAL-SEARCH` as a fast arithmetic rejection rule.

# Related items

`LEM-TAME-CHARACTER-GRADED`; `THM-LOCAL-SWAN-DIVISIBILITY`; `COMP-LOCAL-ARITHMETIC-CHECKS`; `ALG-LOCAL-SEARCH`.
