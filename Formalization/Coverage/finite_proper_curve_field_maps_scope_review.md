The first theorem starts with true original integral proper smooth curve Schemes over an
algebraically closed field and a true constant-field algebra embedding of their actual generic
stalks. Finite dimension and separability of THIS embedding are explicit hypotheses.
It constructs an actual finite surjective Scheme morphism, its actual original base diagram,
and exact equality of its actual generic-stalk pullback with the input embedding.
No curve model, affine chart presentation, valuation stalk, map finiteness or source lift is supplied.

The second theorem is more general: an actual proper surjective morphism between integral
smooth relative-dimension-one curves is finite whenever its actual generic-stalk pullback is
finite separating. No compatibility between the two smooth structure maps is required.
The original actual Scheme morphism is preserved throughout.

The proof works on EVERY true target affine open. Smoothness derives the genuine Dedekind
coordinate ring and all source valuation stalks. The actual source full preimage need not
initially be affine. Genuine open-immersion generic-stalk RingEquivs and their original
restriction square transport the original finite separating extension to the actual restricted
generic stalks. The actual affine chart's original structure map identifies its exact fraction-field
algebra action, with no replacement by an abstract equivalent field.

Over an arbitrary Dedekind ring, a finite separating extension of its actual fraction field has
finite integral closure. The proof constructs its Spec, actual finite structure morphism, true
Dedekind coordinate algebra, and actual generic-stalk RingEquiv with the original upstairs field.
This equivalence fixes EVERY original base-ring element. All actual normalization stalks are
valuation rings, including the generic one. The actual proper valuation source and actual finite
normalization have a constructed SchemeIso over the ENTIRE base Spec, by the previously
proved genuine proper valuative extension and sheaf gluing. Thus finiteness transfers to the
original full preimage and Zariski locality proves finiteness of the original morphism.

The generic normalization theorem requires separability over arbitrary Dedekind bases; it does
not claim arbitrary inseparable normalization is finite. The smooth curve terminal theorem
therefore retains literal finite separability of the original field embedding. No etaleness follows
from this theorem alone. Identifying a concrete quadratic field with an actual smooth proper
model, or deriving its finite separability from a canonical pencil, remains a separate task.
Neither original same-source common-cover leg is manufactured by this finiteness foundation.
