\(1\to N\to G\to PSL_8(\mathbf F_5)\to1\) is exact, the ENTIRE kernel

\[\dim_{\mathbf F_2}N/\Phi(N)\ge97,344,\qquad |N|\ge2^{97,344},\]

\(C_5^{16}\), together with the actual \(SL_4\times SL_4\) Levi image,
forces a nonzero character orbit of size at least
\((5^4-1)^2/(5-1)=97,344\).

The result applies to the actual full-linear source sector if its entire
projective kernel is a two-group, using the separately established
noncentrality. An arbitrary even kernel is not enough. The bound is
consistent with the abstract elementary abelian two-kernel existence
theorem. No upper bound on the original common-cover degree or carrier
genus is supplied, so no geometric contradiction follows. BOTH actual
finite étale maps from the SAME source remain required.
