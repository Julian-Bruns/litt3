# The ten finite fixed-X branch roots form a strong additive Sidon set

Version1,3 October2026. Independently accepted in the [whole genus-two audit](../../Research/audits/Q0_FOUR_GENUS_TWO_WHOLE_AUDIT_2026_10_03.md). The fresh55-sum assertion on accepted stored branch roots passed in0.000045 CPU seconds.

Let R be the ten distinct roots of the fixed polynomial P defining X:y³=P(x). If r1+r2=r3+r4 with all ri∈R, including repeated roots, then the unordered pairs {r1,r2} and {r3,r4} coincide. In particular R contains no THREE distinct roots in arithmetic progression and no FOUR distinct roots forming two pairs with the same sum. This property survives affine changes of x.

Consequently no separating degree-FOUR map f:B→P¹ with g(B)∈{1,2}, only local indices ONE or THREE, finite branch values contained in R, and infinity profile(3,1), can satisfy f∘j=2C−f for an automorphism j of B and C∈k. This is a map-level symmetry exclusion, not a common-cover exclusion.
