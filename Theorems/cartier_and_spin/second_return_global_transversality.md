# A global filtration and modification constraint on actual second returns

Version 1, 24 September 2026. Use the actual nineteen-coordinate
family R_xi and fixed K of
[rank-three extension geometry](rank_three_extension_return_geometry.md).
Put L=O(-O), E_xi=F_abs^{2*}R_xi and let P_C be the pure-v P5
supported on coordinates13,...,18.

The distinguished saturated O(8O) in F_abs^{2*}K defines B_xi by
\[
0\to O(-25O)\to B_\xi\to O(8O)\to0,\qquad
0\to B_\xi\to E_\xi\to O(17O)\to0.
\]
For every geometric xi outside P_C, Hom(L,B_xi)=0. The proof uses
two exact module certificates covering all projective charts, not a
point search or selected coordinate faces.

Every stable strict second return consequently gives
\[
0\to B_\xi\to K\to O_D(17O)\to0,\qquad
D=\operatorname{div}(\delta)+18O,
\]
where delta is nonzero in the fixed seven-dimensional space
V_18 spanned by y,xy,x^2y and the four polynomial rows
\[
(1,0,0,0,17,2,1),\quad(0,1,0,0,22,21,22),\quad
(0,0,1,0,13,18,23),\quad(0,0,0,1,16,1,15).
\]
Rows use ascending F25 codes. D may be nonreduced and contain infinity.

For an actual nonzero quotient morphism phi:E_xi->K outside P_C,
the determinant of its two rows together with the fixed row
(0,-b_*,a_*) is a section delta_phi in V_18. It vanishes identically
exactly when phi has generic rank one; every such source is
nonperiodic at all positive Frobenius periods. In generic rank two
the cofactor zero divisor Z has degree at most18, and phi is
surjective exactly when Z=0. On that surjective locus, injectivity
of the negative-line matrix Q is equivalent to a nonzero induced
extension class eta. A return still requires [eta]=[xi] and stability.

No nonempty stable return, global return exclusion or unmarked
common-cover decision is asserted.
