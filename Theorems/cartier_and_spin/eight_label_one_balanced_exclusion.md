# One balanced endpoint is impossible in the uniform eight-label system

Version1,27 September2026. Consider the four common-moment endpoint
equations with eight labels at each end, exactly two labels of each
of the four root types, and moments in K0=F_(5^14). There is no solution
if EITHER endpoint is a union of two complete four-root blocks, with
arbitrary repeated phases and arbitrary nonzero geometric scalar.

Moreover, every remaining solution either has two half-turn-invariant
endpoints and scalar in F_(5^28), or has two non-half-turn endpoints.
Here half-turn invariance means m_(i,j)=m_(i+2,j) for every phase.
In particular a scalar of degree four over K0 forces both endpoints
to be non-half-turn.

The proof uses a degree-seven field norm, the uniform integer bound
0<=m_(i,j)<=2, and a small exact two-trace exclusion, repeated in
independent absolute and relative field arithmetic. This strengthens
the earlier exclusion requiring BOTH endpoints to be balanced. It does
not decide the full pole24 system or the unmarked common-cover problem.
