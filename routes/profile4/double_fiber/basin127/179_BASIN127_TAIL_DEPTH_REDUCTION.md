## Coefficient-depth lemma

For a tail label \((a,b)\), the raw column formula extracts

\[
d=35-a-b,\qquad
[u^d]\,q^{\,b-2}t^{-1}.
\]

The truncation \(t^{-1}\bmod u^{d+1}\) depends on the derivative series only
through degrees \(5,\ldots,5+d\).  In the triangular repeated-branch
recurrence, these in turn use branch coefficients only through
\(w_{5+d}\).  Therefore

\[
\boxed{\text{tail degree }d\text{ requires repeated data only through }
w_{5+d}.}
\]

The missing implementation reported that the three \(\Phi\)-equations use
only \(w_1,\ldots,w_6\).  Their explicit formulas are not retained, so this
extra dependency statement is not independently checked here.
