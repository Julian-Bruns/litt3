# The canonical different gives an actual pointed norm function

Version1,2 October2026. New computation-free author implication awaiting
focused review. It retains both actual maps, not just divisor classes.

Use the actual ramified higher-genus spin normalization φ:T→Γ, degreeκ,
q:T→Y étale Galois, and canonical discrepancy N=M¹⁶ωΓ^-1. Its canonical
different section s∈H0(T,φ*N) has divisor q*P, with local index2 there.
Put G=Gal(T/Y), k=|ker(G→AutΓ)|∈{1,3}, B=Γ/(G/K).

There are integers r,u with r≥1,u≥1, k|r, and κ=r(2+u) such that
EVERY ramified target fiber ofφ has r index-two points and ru unramified
points. Its stabilizer inG has order EXACTLY r. The induced actual
Y→B fiber is (2r/k)P+(r/k)(Q1+...+Qu), with distinct Qj≠P.

The invariant rational norm ratio gives a NONCONSTANT actual function
f∈k(Y) with the exact divisor
\[
\operatorname{div}(f)=r(Q_1+\cdots+Q_u-uP).
\]
In particular κ−2r=ru is a nongap atP, and the residual degree-zero
class [Q1+...+Qu−uP] is r-torsion.

At κ=6, necessarily k=1 and r=1or2. For r=2 the two points P,Q1 are
distinct Weierstrass points and f is the hyperelliptic pencil. For either
selected endpoint the actual degree-six Y→B has target P1 and its
complete branch profile is one of the five types in the proof. No type
is excluded or constructed by this norm theorem.
