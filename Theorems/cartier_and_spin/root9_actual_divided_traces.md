# Seven small actual-source equations in the root-nine linear family

30 September2026. Use the original root-nine degree140 family, its
actual residual source and original parameter units from the
[universal linear model](universal_degree140_linear_square_model.md).
Restrict to the primitive, discriminant-nonzero chart; all actual
positive-content cases have already been
[excluded](degree140_root9_actual_content_exclusion.md).
Write v=x-[9], and use the regular primitive coordinate in which
\[
F_\ell(W)=\ell v\phi^2+\phi S+t^3,\qquad
\phi=W^5+\bar Q,\qquad S=aW^3+bW^2+cW+e.
\]
On the normalization C of the critical quadratic S'=0 put
\[
\eta=(3b-aW)/2,\quad \eta^2=b^2+2ac,\quad
\Lambda=-\frac{\phi S+t^3}{v\phi^2},\quad
\delta_0=3y^2\partial_x+P'(x)\partial_y.
\]
For each (i,j) in
\[
(0,0),(1,0),(2,0),(3,0),(0,1),(4,0),(1,1)
\]
the function-field trace
\[
U_{i,j}(\ell)=\operatorname{Tr}_{k(C)/k(\Lambda)}
 \left(t v x^i y^j\frac{\delta_0\Lambda}{\eta}\right)
\]
is a polynomial of degree at most, respectively,
\[
4,5,5,6,6,7,7.
\]
Every nonzero scale arising from the specified actual everywhere-etale
source is a common zero of all seven polynomials. This assertion uses
the actual split source roots, not merely a square residual norm.

The coefficients have no moving endpoint-content denominators. With
H=h/w, q=w^3 and ell=w*mu, the normalized polynomial
w^(1-j)*U_(i,j)(w*mu) has coefficients in
\[
K[H,q,1/(HqD(q)\Psi(H,q))],
\]
where D is the original linear source denominator and Psi is the
original nonzero small-infinity leading numerator. Their explicit
values and the fixed-endpoint correction are in the proof.

No common-zero exclusion, no decision for another P-root family, and
no solution of the unmarked common-cover problem is asserted here.
