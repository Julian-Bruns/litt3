# An exact atlas for actual nonsplit quotients after second Frobenius

Version1, 25 September2026. Use the actual nineteen-coordinate extensions
R_xi and L=O_X(-O) of [global transversality](second_return_global_transversality.md).
Set E=F_abs^{2*}R_xi and work outside the pure-v P5. For an actual
map phi:E->K with Hom(E,L)=0 define
\[
V_\phi=\ker\bigl(\phi^*: \operatorname{Ext}^1(K,L)
                  \longrightarrow\operatorname{Ext}^1(E,L)\bigr).
\]
If phi has generic rank two and torsion cokernel of length d, then
dim V_phi=1 when d=0, and dim V_phi=d when d>0. The latter length
retains all multiplicities and satisfies d<=18. At d=1 its unique
projective target extension lies on the strictly semistable surface Sigma.
Thus a one-dimensional V_phi with stable target and generic rank two
forces an actual surjection.

On the necessary window rank T(xi^25)=34 and rank Q(xi^25)=16, there
is a verified43x35 matrix A_phi=[M_phi|Q] with ker A_phi identified
with V_phi, and a44x35 one-row augmentation N_phi such that
\[
\phi\text{ is an actual nonsplit surjection}
\quad\Longleftrightarrow\quad
\operatorname{rank}A_\phi=34,\quad\operatorname{rank}N_\phi=35.
\]
The first nineteen coordinates of a kernel vector of A_phi give the
actual target extension eta. Stable second return is therefore exactly
eta proportional to xi on this domain with xi outside Sigma. Absolute
Frobenius raises both coefficients and functions to the25th power.

The atlas and its lift tensors are constructed and checked in all
nineteen coordinates over arbitrary field extensions. Its domain has
not been shown nonempty or empty; no stable fixed point is decided.
An exact criterion is not a solution of those existence questions.
