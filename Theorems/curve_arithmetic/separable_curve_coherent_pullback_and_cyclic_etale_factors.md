# Coherent pullback is injective exactly when no cyclic characteristic-degree étale factor exists

Version1,3 October2026. Whole root review [PASS](../../Research/audits/RANK_THREE_SOCLE_AND_ORTHOGONAL_ROW_AUDIT_2026_10_03.md). No computation is used.

Let k be algebraically closed of characteristic p>ZERO, and let f:T→C be a finite separable map of smooth projective connected curves. Then the following are equivalent:

- f*:H¹(C,O_C)→H¹(T,O_T) is injective.
- There is no connected finite étale C_p-cover C′→C through which the ACTUAL f factors.
- H⁰(C,f_*O_T/O_C)=ZERO.

The possible kernel has bijective semilinear Frobenius; a nonzero kernel supplies an actual Artin–Schreier factor of f. This concerns coherent cohomology of O only, not arbitrary twisted H¹ or a presumed étale refinement.

In particular, if the actual field extension k(T)/k(C) is primitive and its degree is NOT p, coherent pullback is injective. Applied to the retained primitive degreeTEN map φ:T→Γ in characteristicFIVE, this gives H⁰(Γ,φ_*O_T/O_Γ)=ZERO. The same vanishing holds for the unit-orthogonal quotient E°/O_Γ used in the actual twisted-orthogonal row.

Both original common-cover maps remain on the same source. This does not assert injectivity for the original étale Y leg, which may itself have characteristic-degree factors, or remove a meromorphic twisted boundary class.
