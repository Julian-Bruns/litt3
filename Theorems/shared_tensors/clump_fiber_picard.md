# The clump fibers detect common line bundles and the exact tangent order

Version2,20September2026. The torsion step now uses finite étale
descent in every genus, replacing the former first-Witt argument.
Let $k=\overline{\mathbf F}_p$, $p$ odd,
and retain an ACTUAL coreless finite étale span
$X\xleftarrow f Z\xrightarrow gY$ with $g(Y)=2$. Assume that
there is no shared regular one-form and that its unique clump has
reduced common divisor $S$, with $R=\deg S_Y\ge2$. Thus
$R\equiv-1\pmod p$. These hypotheses cover every possible clump
of either selected pair.

Let $P$ be the group of common line-bundle triples with their
specified source identifications. Let $\Gamma_S$ be the connected
bipartite graph whose vertices are $S_X\sqcup S_Y$ and whose
edges are $S_Z$, with the actual endpoint maps. Restriction gives
\[
\operatorname{res}_S:P\longrightarrow
\operatorname{Pic}(\Gamma_S)=H^1(\Gamma_S,k^\times).
\]
A line in the target is a line at every vertex with an isomorphism
along every edge. Its class is zero exactly when it has a nonzero
compatible section. Write $\Omega$ for the common canonical line.

## Exact kernel of restriction

The ONLY common lines trivial on the clump fibers are
\[
\ker(\operatorname{res}_S)=\mathbf Z\,[\Omega(S)].
\tag{1}
\]
In particular every nontrivial degree-zero common torsion line is
detected by transport around some loop of the actual clump graph.
The conormal identification trivializes $\Omega(S)|_S$ canonically.
More generally, prime-to-p common torsion is detected at any clump
in ANY genus, by [finite clump descent](clump_finite_descent.md).

If $e_0$ generates the $Y$-degree image of $P$ and $T=P_{\deg0}$,
the finite restriction image has order
\[
\left|\operatorname{res}_S(P)\right|
=\frac{R+2}{e_0}|T|.
\]
It has order prime to p. This is a statement about k-points of the
common Picard group, not a claim that its group scheme is reduced.

## The tangent transport order is exactly the weight plus multiplicity

Let the primitive common canonical tensor have weight d and divisor
eS, so $2d=eR$. The subgroup of $k^\times$ generated by the
cotangent transport multipliers around ALL loops in $\Gamma_S$
has order
\[
\boxed{h=d+e=\frac{e(R+2)}2.}
\tag{2}
\]
Equivalently, $\operatorname{res}_S(\Omega)$ has EXACT order h.
This strengthens the immediate divisibility h by d+e to equality.
At a four-point characteristic-five clump the order is exactly 3e.
Neither a finite formal holonomy group nor a global automorphism
of that order is asserted.

## Stronger restrictions on every common line extension

Put $J(L)=H^1_{\rm common}(L^{-1})$ for a positive-degree common
line. Nonvanishing implies
\[
L\in\langle\Omega,\mathcal O(S)\rangle\subseteq P.
\tag{3}
\]
Thus other common torsion directions never contribute to a positive
line extension, even at arbitrarily large degree.

More precisely suppose $D=\deg L_Y>2R$ and put
$b=\lfloor(D-1)/(2R)\rfloor$. Then
\[
\dim J(L)\le
\#\{1\le c\le b:\ L\Omega^c\in\mathbf Z[\Omega(S)]\}.
\tag{4}
\]
The allowed c, if there are any, form ONE congruence class modulo h.
In particular $\dim J(L)\le\lceil b/h\rceil$. Membership in
(4) is an identity of actual common line classes, not just degrees.
The bound does not assert that higher principal parts exist.

The simple-pole part is exact. For $D>R$, a nonzero common simple
principal part exists if and only if
\[
L=\Omega^j((j+1)S)\quad\text{for an integer }j\ge1.
\tag{5}
\]
It then gives a canonical nonzero line in J(L), from the jth power
of the conormal unit. Consequently the entire range $2R<D\le4R$
is now explicit: J(L) is one-dimensional exactly for
$L=\Omega(2S)$ and, when $R\ge4$, $L=\Omega^2(3S)$; it vanishes
for all other common lines in that range.

This is conditional on an existing clump. It neither constructs one
nor excludes the remaining common-cover spans. Author proof using
actual cyclic torsors, including disconnected component diagrams.
