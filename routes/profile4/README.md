# Profile-4 route

This route starts only after [Task 01](../../tasks/01_PROFILE_EXTRACTION.md)
has produced the fixed genus-11, degree-35 two-map profile.

Read
[file 162](162_PROFILE4_HIGHPOINT_FIBER_COUNT_LEMMA.md) first. It contains
the quotient, field-generation, inversion, and paired-entry-zero proofs, so
the dated synthesis is not needed for these reductions. It leaves three
approach folders:

| Branch | Directory | Current state |
| --- | --- | --- |
| Entry-one high-point coincidence | [entry-one route](entry_one/README.md) | Open; file `175` isolates the Cartier divisor-lifting class and file `176` its norm consequences. |
| No high-point coincidence | [no-highpoint route](no_highpoint/README.md) | Open extraction and normalization-aware elimination gates in file `170`. |
| Entry-zero coincidence | [double-fiber route](double_fiber/README.md) | Open specialization/coverage gate; the retained \(c=d=2\) formal tower is conditional. |

The profile-4 nonexistence theorem needs all three branches. It does not by
itself prove visibility: Task 01, or another valid bridge from a non-visible
self-correspondence to the profile problem, is also required before the
global conditional common-cover theorem applies.
