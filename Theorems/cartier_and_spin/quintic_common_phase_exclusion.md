# Quintic endpoints cannot both use a single phase

Version1, 27 September2026. In any actual pole-fifteen comparison,
at least one endpoint multiset uses two distinct29th-root phases.
The root labels at an endpoint are otherwise arbitrary, with repetitions.
In particular this excludes the entire case of one phase at each end,
not just five copies of a single root and phase.

More precisely, for any two nonpure five-label multisets Q,H each
using a single phase, the necessary endpoint determinant has no
solution x,y in K0=F_(5^14):
\[
(E_Q/[22]-\bar x)(E_H/[22]-x)
 -(C_Q/[22]-y)(C_H/[22]-\bar y)\ne0.
\]
The sums and bar use the [five-label conventions](five_label_endpoint_rank.md).
Pure cases are excluded by the actual one-endpoint theorem, not by
this particular finite determinant statement.
