# Uniform exclusion of the one-step Hermite boundary

Version1, 26 September2026. Under the actual same-source hypotheses and
notation of [strict Hermite bounds](klein_four_strict_hermite_bound.md),
every nontrivial V4 character satisfies
\[
c_i\le14+2d_i,\qquad h_i\le17+\lfloor c_i/2\rfloor.
\]
Consequently
\[
g(S)\le48+j-\tfrac12\#\{i:c_i\text{ is odd}\}\le77.
\]
The earlier bound g<=n remains valid. Combined with the existing grid
theorem this excludes degrees89..182 and leaves14..88 undecided. The
uniform character bound is stronger than that numerical interval test.

The proof excludes the full boundary c_i=15+2d_i, including vanishing
leading character values and the polynomial degree29 case. It uses
complete finite tests only for forced endpoint labels and cyclotomic
subsets. It neither constructs an actual comparison nor extracts one
from an arbitrary common-cover span.
