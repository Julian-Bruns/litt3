# Twelve-torsion Abel points have bounded exceptional parameter support

Version1,3 October2026. Computation-free author implication awaiting independent review.

For Y_t:v²=u(u−1)(u−2)(u−3)(u−t), t^5−t≠0, with Weierstrass origin O at infinity, the set of geometric parameters admitting a NON-Weierstrass P with12[P−O]=0 is finite, Frobenius-stable, and has at most153600 points. Consequently any parameter of F5-degree greater than153600 admits no such point; in particular the selected MAIN endpoint does not. BACKUP has none by its accepted W1[24] arithmetic.

The bound uses the established complete BACKUP torsion result and polynomial Hasse-jet criterion; it requires no new arithmetic computation or certificate.
