# The degree-zero centered Frobenius bundles

Version1,20 September2026. Use an actual clumpless finite étale span
of proper hyperbolic curves over an algebraically closed field of odd
characteristic $p$, with $p\nmid g(Y)-1$. On $C^{(r)}$, put
\[
T_{r,C}=(F_C^{[r]})_*\omega_C^{(1-p^r)/2},\qquad T_{0,C}=\mathcal O_C.
\]
All these are actual common bundles by étale base change. For every
$r\ge0$, $T_r$ has rank $p^r$, degree zero, a canonical perfect
symmetric $\mathcal O$-valued pairing, and is common-simple. For
$r>0$ it is stable on each endpoint but not strongly semistable:
its $r$th Frobenius pullback has grades
\[
\omega^{(1-p^r)/2},\omega^{(3-p^r)/2},\ldots,
\omega^{(p^r-1)/2}.
\]
Its scalar common Atiyah class
$\operatorname{id}_{T_r}\otimes a(\omega)$ is nonzero.

A common connection on $T_r$, if it exists, is unique, preserves
the symmetric pairing, and has zero $p$-curvature. It is equivalent
to an ACTUAL common Frobenius antecedent $F^*U=T_r$. Existence is
NOT decided here. The self-duality identity is
\[
a(T_r)+a(T_r)^\dagger=0,
\]
so the nonzero scalar class does not exclude a connection.

In characteristic5 the first case $T_1=F_*\omega^{-2}$ is a canonical
rank-five degree-zero orthogonal bundle. It is a distinct remaining
connection problem from $F_*^{[s]}B$, whose positive self-duality
weight supplies the now-settled obstruction. The hypotheses do not
assert the existence of a clumpless span or a common connection.
[Proof](../../Proofs/cartier_and_spin/centered_frobenius_common_bundle.md).

The subsequent [skew detection theorem](common_projective_atiyah_detection.md)
identifies the first connection question with a SECOND common
projective Cartier descent of an actual rank-two Bol bundle.
It proves an arithmetic subcase and bounds the length of any such
common descent chain over a fixed finite field; universal first-step
nonvanishing remains open.
