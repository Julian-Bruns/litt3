# Actual split degree thirteen with one to three common infinity points is impossible

Version1, 3 October2026. [Independent focused audit PASS](../../Research/audits/CANONICAL_THIRTEEN_SPLIT_COMMON_INFINITY_CUBIC_ADJOINT_AUDIT_2026_10_03.md). Mathematical scope is unchanged by canonical metadata integration.

Use the fixed characteristic-five genus-nine curve X:y³=P(x), monic degree10, infinity O, θ=dx/y² with divθ=16O, and q₀(x)=(x+1)²+d with d≠0. Let h₁,h₂:C₀→X be TWO actual finite étale maps of degree13 from the SAME smooth projective connected curve. Retain the actual pullbacks xᵢ,yᵢ,θᵢ,Hᵢ and the actual split cubic-index-one identities
\[
k(C_0)=k(t,x_1,x_2),\quad q_0(x_2)=t^6q_0(x_1),\quad
\operatorname{div}(t)=H_1-H_2,\quad \theta_1=\kappa t^{16}\theta_2.
\]
Suppose J=min(H₁,H₂) has degree c with1≤c≤3 and t is nonconstant. Then the configuration is impossible.

Together with [the independently audited disjoint-infinity exclusion](canonical_thirteen_split_disjoint_cubic_adjoint_exclusion.md), this excludes every actual split degree-thirteen carrier whose actual residual t-degree13−c is at least10. The proof of this companion does not presume that residual-degree bound for arbitrary spans.

Both actual endpoint maps stay on C₀ and any original endpoint maps from T stay on their SAME T. No complete common fiber, simultaneous endpoint normal closure, nonsplit comparison or arbitrary polynomial model is used. Common infinity degree at least4, higher joint degrees and the unmarked common-cover problem are outside the conclusion.
