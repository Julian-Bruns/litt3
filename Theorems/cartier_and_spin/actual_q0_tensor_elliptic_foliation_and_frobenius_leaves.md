# The elliptic joint surface has a Frobenius leaf criterion

Version1,3 October2026. New scoped reduction, pending independent review. This is not tensor recognition or a common-cover exclusion.

Work over k=F5bar with the fixed curve X:y³=P(x), θ=dx/y², quadratic q=q0, and primitive Q satisfying Q′=qP. Set X′:y³=P(x),w³=q(x), E:w³=q(x), λ=dx/w², and H=Qw⁵/y⁵. Thus η=w⁸θ=dH. Fix c∈k×.

On X′×X′ take the diagonal cubic action scaling BOTH yi by ζ and fixing xi,wi. The invariant surface W has function field
\[
k(W)=k(E\times E)(t),\qquad t^3=P(x_2)/P(x_1),\quad t=y_2/y_1.
\]
Put a=t(w1/w2)⁵ and J=(H1−cH2)³. These are invariant functions and
\[
a^3=R_1/R_2,\quad R_i=q(x_i)^5/P(x_i),\qquad
J=\frac{(Q_1w_1^5-cQ_2w_2^5/t^5)^3}{P_1^5}.
\]
The tangent equation η1=cη2 becomes λ2=c⁻¹a²λ1. It defines a rational rank-one p-closed foliation on W. There is a nonzero rational derivation U representing it with U⁵=U, whose exact constant field is
\[
\ker U=k(W)^5(J),\qquad [k(W):\ker U]=5.
\]
In particular J is a first integral for a purely inseparable quotient, not a justification that J is constant on each algebraic tangent curve.

Now let h1,h2:S→X be two actual finite étale maps from the SAME smooth projective source with proportional pullbacks of q⁸θ³. Normalize their actual two-X joint image C0 and its specified common cubic root C0′, choosing roots so η1=cη2. Let D be the actual composite of the two elliptic fields. As in the separately recorded cubic-alternative reduction, k(C0′)=k(D)(y1) with index ONE or THREE, and t belongs to k(D). The image of D lifts to W, and the exact tangent condition is
\[
J|_D\in k(D)^5.
\]
In index THREE, if H1−cH2=K⁵ on C0′, then K³∈k(D) and J=(K³)⁵. In index ONE, the same conclusion is immediate. Conversely the displayed condition implies d(H1−cH2)=0 on C0′. Thus this criterion retains both cubic possibilities; it does not eliminate a nonconstant fifth-power first integral.

If a is constant on the actual joint curve, the elliptic differential lines are proportional and the accepted differential-recognition theorem identifies the original X-fields. No claim that a must be constant, that D has genus one, or that a separable tangent curve has étale X-projections is made. An original Y-leg stays on S and is not replaced by the auxiliary root or joint curve.
