# A single unused pole excludes both small-character boundaries

Version1,26 September2026. Under the actual same-source V4 hypotheses
and the [uniform character bounds](klein_four_uniform_pencil_gap.md),
if e<=28 then every character satisfies
\[
d_i=0\Longrightarrow c_i\le13,
\qquad d_i=1\Longrightarrow c_i\le15.
\]
Therefore g<=47+j whenever e<=28 and j<=26. In particular this
holds for every remaining actual degree14..88 comparison with e<=28.

Together with the existing grid bounds, degree88 now requires full
common-pole support e=29 and one of only two scalar profiles
\[
(g,s,a,j_1,j_2)=(70,7,10,22,0),\qquad(71,6,7,23,0).
\]
The corresponding triples (c_i;d_i), up to permutation, are respectively
\[
((14,14,16);(0,0,1)),
\]
and
\[
((14,14,18);(0,0,2))\quad\text{or}\quad((14,16,16);(0,1,1)).
\]
These are necessary profiles, not curves. Degrees14..88 and both original
unmarked common-cover problems remain open.
