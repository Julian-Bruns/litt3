# Middle-character correction rigidity and a closed source boundary

Version1, 25 September2026. Use the actual K, L=O_X(-O), source
extensions R_xi and second absolute Frobenius Hom atlas from
[second_return_global_transversality](second_return_global_transversality.md).
The [character reduction](second_return_character_slices.md) restricts
every nonzero middle-character map to the following sixteen-coordinate
source atlas:
\[
u=y^2\sum_{i=1}^5a_i x^{i-6},\qquad
v=y\sum_{i=1}^5b_i x^{i-6}+y^2\sum_{i=1}^6c_i x^{i-7}.
\]
Write the complete lower map as
\[
f=yp(x)\ne0,\quad\deg p\le7,\qquad
\alpha=A(x)+yd(x)+\gamma y^2,
\quad\deg A\le6,\quad\deg d\le3.
\]
For every nonzero geometric source and every such actual global map,
gamma=0. If additionally Hom(F_abs^{2*}R_xi,K) is one-dimensional,
then d=0 too. This correction rigidity does not assume stability or
vanishing of Hom to L.

In the stable quotient window
\[
\dim\operatorname{Hom}(F_{abs}^{2*}R_\xi,K)=1,\qquad
\operatorname{Hom}(F_{abs}^{2*}R_\xi,L)=0,
\]
one necessarily has (a1,a2,a3) nonzero. Thus the entire closed
boundary a1=a2=a3=0 is excluded. More strongly, with polynomial-only
correction there is no nonzero lower-map vector on that boundary
whenever the ten-coordinate block (a1..a5,b1..b5) is nonzero.

These statements hold over the full algebraic closure and retain all
source rank-drop loci. The remaining three first-nonzero-coordinate
strata, the first-character and mixed-character cases, and stable
strict second returns are not decided.
