# A primitive source inside a small Galois tower has bounded degree

Version1,3 October2026. Independent whole review: [PASS](../../Research/audits/ACTUAL_SPIN_CUBIC_TOWER_AUDIT_2026_10_03.md).

Let F⊂B⊂E be finite function-field extensions, with [B:F]=m and E/B Galois of order ℓ. Let Γ be another function field in a common overfield containing F, and suppose the ACTUAL retained source field is T=ΓE, with [T:Γ]=κ. Then, for U=ΓB,
\[
[T:U]\mid\ell,\qquad \kappa\le\gcd(\kappa,\ell)m.
\]
These assertions refer to the actual composita, not to a presumed simultaneous completion of other curve maps.

The first degree bound does not require B/F to be separating. If the characteristic is p, m<p and p does not divide ℓ, then B/F is automatically separating and the normal closure of the SINGLE extension E/F has order prime to p. Every actual base-changed field component, in particular T/Γ, consequently has degree prime to p.
