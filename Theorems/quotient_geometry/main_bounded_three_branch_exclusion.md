# The selected main partner has no small tame three-branch map

Version1,2 October2026. New bounded counting implication awaiting focused review.

Let k=bar(F5) and Y_t:v²=u(u−1)(u−2)(u−3)(u−t), t≠0,1,2,3.
Put C=720·42·(42!)². If [F5(t):F5]>C, then Y_t admits NO separating
map of degree at most42 to P1 which is tamely ramified and has at most
THREE geometric branch values. The selected MAIN parameter satisfies
this inequality by its already established selection bound.

Consequently, in the tame ramified spin normalization with effective
degree n=κ/k≤42, every TRIANGULAR quotient signature is excluded on
MAIN if the distinguished ramified spin fiber is itself a branch value
of Γ→Γ/(G/K), equivalently r/k>1. The case r/k=1 introduces an extra
moving branch value and is NOT excluded. Quadrilateral signatures and
the BACKUP endpoint are also outside this consequence.

This excludes actual endpoint maps satisfying the stated branch bound;
it neither constructs an étale span nor decides the common-cover problem.
