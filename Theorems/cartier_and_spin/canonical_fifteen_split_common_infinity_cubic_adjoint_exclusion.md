# Actual split degree fifteen with one to five common infinity points is impossible

Version1, 3 October2026. [Independent whole audit PASS](../../Research/audits/CANONICAL_FIFTEEN_SPLIT_COMMON_INFINITY_CUBIC_ADJOINT_AUDIT_2026_10_03.md), with no required corrections. No computation is used.

Use the fixed characteristic-five genus-nine curve X:y³=P(x), monic squarefree degree10, infinity O, θ=dx/y² with divθ=16O, and q₀(x)=(x+1)²+d, d≠0. Let h₁,h₂:C₀→X be TWO actual finite étale maps of degree15 from the SAME smooth projective connected source, retaining their actual functions xᵢ,yᵢ,θᵢ and reduced infinity divisors Hᵢ. Suppose t is nonconstant and the actual split cubic-index-one identities hold:
\[
k(C_0)=k(t,x_1,x_2),\quad q_0(x_2)=t^6q_0(x_1),\quad
\operatorname{div}(t)=H_1-H_2,\quad\theta_1=\kappa t^{16}\theta_2,
\qquad\kappa\ne0.
\]
If J=min(H₁,H₂) has degree c with1≤c≤5, the configuration is impossible, for every distribution between the two actual conic boundary sections.

In a retained-source carrier where15−c≥10 is independently known, this deletes every POSITIVE-overlap split degree-fifteen case. The disjoint c=0 case is outside this theorem. Both actual maps remain on C₀, and any original endpoint maps remain on their SAME T. The proof requires the actual cubic coordinates, exact canonical identity and normalization conductor; arbitrary curves or polynomial models on the conic surface do not satisfy these source hypotheses automatically.

No nonsplit or higher-degree conclusion, endpoint descent or unmarked common-cover solution is asserted.
