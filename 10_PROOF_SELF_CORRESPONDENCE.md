# Statement

Let `k = \bar F_5`. The central stack is

`S = P^1_k(31,31,31)`.

It is also represented in the project as

`S = [Y/C31]`, where `Y : y^31 = x(x-1)` and `C31` acts by `y ↦ ζy`.

The natural `S3`-action permuting the three stacky points has quotient

`S0 = S/S3 ≃ P^1_k(2,3,62)`.

The quotient map is denoted

`pi0 : S → S0`.

# Context / motivation

This is the basic object for the entire common-cover / algebraic commensurator project. The main theorem says that all finite étale algebraic self-correspondences of `S` should come only from the six evident `S3` symmetries.

The presentation through `Y` is used in lift-through-atlas arguments and in the conditional common-cover consequence. The quotient `S0` is the target through which all allowed self-correspondences are expected to factor.

# Proof or evidence

This file records definitions and accepted identifications, not a new proof.

The quotient shape `S/S3 ≃ P^1(2,3,62)` is part of the stable project setup. The `S3` quotient is the stack-theoretic form of the triangle-group inclusion associated with permuting the three equal stacky points of order `31`.

# Dependencies

None.

# Failure points / caveats

- Keep `S = P^1(31,31,31)` distinct from its atlas `Y`; arguments about curves must track whether maps are to `S`, `Y`, or the coarse space.
- Keep `S0 = S/S3` distinct from an arbitrary finite over-orbifold `O`.
- Do not replace the characteristic-5 theorem by the complex triangle-group theorem without a valid specialization/lifting argument.

# How this is used

This definition feeds into:

- `DEF-FINITE-ETALE-SELF-CORRESPONDENCE`;
- `DEF-ALG-COMMENSURATOR`;
- `THM-TAME-COMMENSURATOR`;
- `PROP-CONDITIONAL-COMMON-COVER`;
- all over-orbifold and local-ramification reductions.

# Statement

A finite étale self-correspondence of `S` means the following data:

- a connected smooth proper Deligne–Mumford curve `C` over `k = \bar F_5`;
- two representable finite étale maps

`u, v : C → S`.

The project writes this compactly as `C ⇉ S` or `u,v:C→S`.

# Context / motivation

The main theorem is not a statement about automorphisms of `S` alone. It concerns all connected finite étale correspondences with arbitrary connected source `C`. This is why global-envelope and commensurator issues appear: a correspondence may not be an automorphism or a quotient map `S→O` on its face.

# Proof or evidence

This is a definition. It is stable in the project materials.

Representability is part of the definition and should not be dropped: it controls inertia behavior and prevents non-representable stack maps from being counted as finite étale correspondences.

# Dependencies

- `DEF-S-TRIANGLE-STACK`.

# Failure points / caveats

- Do not assume `C→S` is Galois.
- Do not assume the two maps `u` and `v` admit a simultaneous Galois refinement over unrelated bases.
- Do not assume the equivalence relation generated by the two pullback groupoids has finite orbits in general.
- The source `C` is connected; this matters when translating factorization through `S×_{S0}S` into a single element of `S3`.

# How this is used

The definition is used in the current bottleneck:

`For every finite étale self-correspondence u,v:C→S, prove pi0∘u ≃ pi0∘v.`

# Statement

The assertion `Comm_alg,\bar F_5(S)=S3` means:

For every connected finite étale self-correspondence

`u, v : C → S`,

one has

`pi0 ∘ u ≃ pi0 ∘ v`.

Equivalently, the map

`(u,v) : C → S × S`

factors through

`S ×_{S0} S`.

Because `S→S0` is the `S3` quotient, for connected `C` this is equivalent to saying that there exists a single `σ ∈ S3` such that

`v ≃ σ ∘ u`.

# Context / motivation

This is the exact algebraic self-correspondence theorem that remains open in the project archive. It is the bridge between the local/over-orbifold work and the intended common-cover counterexample.

# Proof or evidence

No proof is recorded as locked. The project archive treats this as the current bottleneck.

The known strategy is:

1. classify finite étale over-orbifolds `S→O`;
2. prove that every self-correspondence `C⇉S` generates such an over-orbifold in a valid finite way;
3. apply the tame commensurator calculation to conclude that only `S3` remains.

Step 2 is not currently locked.

# Dependencies

- `DEF-S-TRIANGLE-STACK`;
- `DEF-FINITE-ETALE-SELF-CORRESPONDENCE`.

Potential proof dependencies:

- `PROP-CORRESPONDENCE-TO-OVER-ORBIFOLD`;
- `THM-OVER-ORBIFOLD-TAME`;
- `THM-TAME-COMMENSURATOR`.

# Failure points / caveats

- Do not treat `THM-OVER-ORBIFOLD-TAME` alone as a proof of this assertion.
- Do not assume a finite envelope from a general correspondence without proving it in this special case.
- Do not use characteristic-zero lifting unless it controls the single common source `C` and both maps simultaneously.
- Do not use formal Artin–Schreier stabilizer bounds as a replacement for actual finite local ramification.

# How this is used

If proved, this immediately feeds into `PROP-CONDITIONAL-COMMON-COVER`, giving the project’s conditional negative common-cover result for genus-three curves and `Y:y^31=x(x-1)`.

# Related items

# Statement

For

`S0 = P^1_k(2,3,62)`,

the orbifold canonical degree is

`deg K_{S0} = 14/93`.

Consequently, no smooth projective connected genus-three curve admits a finite étale map to `S0`, because such a map would have degree `186/7`, not an integer.

# Context / motivation

This is the numerical obstruction used at the end of the conditional common-cover argument. Once a hypothetical genus-three curve is forced to map finite étale to `S0`, the canonical-degree computation rules it out.

# Proof or evidence

For a stacky projective line `P^1(a,b,c)`, the orbifold canonical degree is

`-2 + (1-1/a) + (1-1/b) + (1-1/c)`.

For `(a,b,c)=(2,3,62)`, this is

`-2 + 1/2 + 2/3 + 61/62`.

Using denominator `186`, this equals

`(-372 + 93 + 124 + 183)/186 = 28/186 = 14/93`.

If `X` has genus `3`, then `deg K_X = 2g(X)-2 = 4`. A finite étale map `X→S0` of degree `d` would require

`4 = d · 14/93`,

so

`d = 4 · 93/14 = 186/7`,

which is impossible.

# Dependencies

- `DEF-S-TRIANGLE-STACK`.

# Failure points / caveats

- This only rules out finite étale maps to `S0`; it does not rule out a common cover before the commensurator bottleneck is solved.
- The argument uses stack canonical degree, not the canonical degree of the coarse `P^1` alone.

# How this is used

This is a terminal obstruction in `PROP-CONDITIONAL-COMMON-COVER`: after `Comm_alg(S)=S3` forces descent to `S0`, the genus-three map is numerically impossible.

# Related items

`PROP-CONDITIONAL-COMMON-COVER`; `DEF-ALG-COMMENSURATOR`; `BOTTLENECK-ALG-COMM-S31`; `DEF-S-TRIANGLE-STACK`.

# Statement

Assume Comm_alg,k(S)=S3. Then no smooth projective connected genus-three curve X/k has a connected common finite étale cover with Y:y^31=x(x-1).

# Context / motivation

This is the final payoff. It converts the algebraic commensurator theorem into a negative answer to the common-cover question.

# Proof or evidence

Given Z→X and Z→Y, compose Z→Y→S. The relation R_X=Z×_X Z produces self-correspondences of S on components. The commensurator hypothesis makes pi0∘b descend to X→S0. But deg K_{S0}=14/93, so genus 3 would force degree 186/7.

# Dependencies

DEF-ALG-COMMENSURATOR, LEM-GENUS-Y, LEM-CANONICAL-DEGREE-S0

# Failure points / caveats

Conditional only. Requires the full self-correspondence theorem, not merely over-orbifold classification.

# How this is used

Once BOTTLENECK-ALG-COMM-S31 is proved, this yields the project counterexample.

# Statement

Candidate reduction:

Given a finite étale self-correspondence

`u, v : C → S`,

refine to a common finite cover `W` and finite groups `A,B` such that

`S ≃ [W/A] ≃ [W/B]`.

Let

`H = <A,B>`

inside an appropriate automorphism group of `W`, and set

`O = [W/H]`.

Then `S→O` should be a finite étale over-orbifold generated by the original correspondence. If valid, the over-orbifold classification applies to `O`, and the main commensurator theorem should follow.

# Context / motivation

This is the most important missing or disputed global step. The over-orbifold work classifies maps `S→O`; the main theorem concerns arbitrary correspondences `C⇉S`. This proposition is the proposed bridge between the two.

# Proof or evidence

The project archive records this as a candidate reduction requiring referee audit, not as locked.

The idea is plausible because each single finite étale map to `S` admits Galois closures after refinement. However, the project also records a false route: one cannot generally assume a simultaneous Galois refinement over unrelated bases. Therefore the proposition must be proved with special hypotheses or replaced by a different argument.

# Dependencies

- `DEF-FINITE-ETALE-SELF-CORRESPONDENCE`;
- `THM-OVER-ORBIFOLD-TAME`;
- warning file `FALSE-SIMULTANEOUS-GALOIS`.

# Failure points / caveats

A valid proof must check all of the following:

1. construction of a single finite cover `W` suitable for both maps;
2. existence and finiteness of the groups `A`, `B`, and `H=<A,B>`;
3. that `O=[W/H]` is a smooth proper connected DM curve;
4. that `S→O` is representable finite étale;
5. that applying `THM-OVER-ORBIFOLD-TAME` forces `pi0∘u ≃ pi0∘v`;
6. that all 2-categorical quotient and descent statements are legitimate.

Do not replace these checks by the false simultaneous-Galois claim.

# How this is used

If this proposition is proved, then together with `THM-OVER-ORBIFOLD-TAME` and `THM-TAME-COMMENSURATOR` it is the likely shortest route to `Comm_alg,\bar F_5(S)=S3`.

If it is false or incomplete, the project bottleneck should be restated as the minimal missing global-envelope lemma.
