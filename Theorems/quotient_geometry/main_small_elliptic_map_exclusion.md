# Bounded elliptic maps have finite parameter support; MAIN avoids degree sixteen

Version2,3 October2026. Version1's degree-SIX implication passed [independent whole-implication review](../../Research/audits/MAIN_SMALL_ELLIPTIC_MAP_EXCLUSION_AUDIT_2026_10_02.md). The uniform bound and degree-SIXTEEN extension passed [focused whole-scope review](../../Research/audits/JOINT_SPIN_KUMMER_SOURCE_AUDIT_2026_10_03.md); no computation.

For Y_t:v²=u(u−1)(u−2)(u−3)(u−t) and EVERY integer N≥TWO, the parameters admitting a nonconstant map of degree at most N to ANY elliptic curve form an F5-Frobenius-stable finite set of size at most N·5^(4N+4). In particular
\[
[\mathbf F_5(t):\mathbf F_5]>N\cdot5^{4N+4}
\]
excludes every such map, including inseparable maps. The selected MAIN parameter satisfies this inequality for N=SIXTEEN and therefore has no elliptic map of degree at most SIXTEEN. The prior N=SIX bound6·5²⁸ remains a special case.

The proof uses only the accepted geometric simplicity of the BACKUP Jacobian as one good specialization. It does NOT assert geometric simplicity of the MAIN Jacobian.

Consequently the order-one branch of the actual elliptic spin isogeny carrier is excluded for MAIN as well as BACKUP. Both original endpoint maps are retained in this scoped contradiction; the remaining spin-image and unmarked common-cover problems are not settled here.
